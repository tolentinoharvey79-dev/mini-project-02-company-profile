# Mini Project 02 – Company Profile Website

## Project Title

**JinTech Technologies – Company Profile Website**

## Introduction

This project is a simple company profile website for JinTech Technologies, a Computer and IT Solutions company. The website provides information about the company, its services, and contact details.

## Objectives

* Create a simple and responsive company profile website.
* Practice Laravel MVC architecture.
* Use Laravel routing and controllers.
* Use Blade templates for the website pages.
* Organize the project using Laravel's folder structure.

## Pages

The website contains the following pages:

* **Home** – Introduction and featured services
* **About** – Company information, mission, vision, and values
* **Services** – List of available IT services
* **Contact** – Contact information and contact form UI

## Services

1. Computer Repair
2. PC Upgrade
3. Software Installation
4. CCTV Installation
5. Network Setup
6. Computer Rental

## Technologies Used

* Laravel
* PHP
* Blade
* HTML
* CSS
* GitHub

## MVC Architecture

The project follows the MVC structure of Laravel.

**Browser → Route → Controller → Blade View → Browser**

Routes handle the URLs, the Controller handles the requests, and Blade Views display the website pages.

## Project Structure

```text
app/
└── Http/
    └── Controllers/
        └── CompanyController.php

resources/
└── views/
    ├── layouts/
    ├── components/
    └── pages/

routes/
└── web.php

public/
```

## Problems Encountered

Some problems encountered during development were incorrect routes, missing views, and minor Blade syntax errors.

## Solutions

I checked the route definitions, verified the file names and folder locations, and corrected the Blade syntax errors. I also tested each page to make sure the website was working properly.

## Reflection

This project helped me understand how Laravel MVC works. I learned how routes, controllers, and Blade views work together to display different pages. I also learned the importance of organizing files properly and using reusable components. Overall, the project gave me more experience in creating a structured website using Laravel.
